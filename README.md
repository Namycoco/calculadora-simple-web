🧮 Sobre el proyecto

Calculadora Simple Web es un proyecto personal de desarrollo web creado para practicar la construcción de una aplicación interactiva desde cero.

La idea es mantener una interfaz sencilla, clara y fácil de utilizar, centrando el proyecto en la interacción del usuario y en el funcionamiento de las operaciones matemáticas.

Aunque se trata de una aplicación pequeña, ha servido como práctica para trabajar conceptos fundamentales del desarrollo frontend.

✨ Funcionalidades

La calculadora está diseñada para permitir realizar operaciones matemáticas básicas de forma rápida y sencilla.

🔢 Operaciones
➕ Suma
➖ Resta
✖️ Multiplicación
➗ División
🟰 Resultado de las operaciones
🧹 Limpieza de la pantalla
🔢 Introducción de números mediante botones
🎨 Diseño

El diseño busca mantener una experiencia sencilla:

Simple → Claro → Funcional

La interfaz evita elementos innecesarios para que el usuario pueda centrarse directamente en la calculadora y en las operaciones que quiere realizar.

El objetivo principal de este proyecto es aprender mediante la práctica y construir pequeñas aplicaciones que permitan mejorar progresivamente mis conocimientos de desarrollo web.
